LICO PRIMOS — Guia de Automação Completa com Make e n8n
Este guia mostra como transformar o prompt OFERTA MASTER PRO em uma operação 100% automatizada usando Make ou n8n, conectando a IA às APIs do Mercado Livre, Amazon e Shopee e disparando as ofertas diretamente nos grupos de WhatsApp e Telegram — sem intervenção manual. O fluxo implementa exatamente o que o prompt faz hoje: garimpo → Centro de Distribuição → verificação de preços → copy → link de afiliado com UTM → disparo programado.

Nota importante antes de começar: o Mercado Livre não oferece API pública para afiliados — os links de afiliado são gerados pelo próprio site/portal do programa de parceiros. Por isso, no fluxo LICO PRIMOS, o Mercado Livre usa uma abordagem híbrida: o n8n/Make navega nas páginas públicas (ou importa planilha CSV) e o prompt/IA gera os links de afiliado. Amazon e Shopee possuem APIs oficiais de produtos/afiliados que automatizam tudo. 1 2

Make vs n8n para o LICO PRIMOS: o n8n é a escolha recomendada para esta operação porque tem nó nativo de HTTP (chama a API da Amazon e da Shopee com facilidade), suporta nodes customizados (existe node da PA-API da Amazon mantido pela comunidade) 3 e roda self-hosted em uma VPS de ~R$ 30/mês com custo zero de licença. O Make é mais simples visualmente e não exige servidor, mas tem limite de operações nos planos gratuitos e menos flexibilidade para scraping e banco de dados. Este guia cobre ambos.

3. O fluxo ponta a ponta (6 módulos)
Módulo 1 — Garimpo automatizado (cron diário)
No n8n:
	•	Nó Schedule Trigger (todos os dias às 6h00);
	•	Nó HTTP Request → PA-API da Amazon (SearchItems com Keywords=ofertas eletrônicos, SortBy=Featured, ItemResources=Images.Primary.Large,Offers.Listings.Price,Offers.Listings.MerchantInfo,Reviews.Rating) 2 3;
	•	Nó HTTP Request → Shopee Open Platform (/api/v2/product/get_items ou importação do CSV do portal de afiliados);
	•	Nó HTTP Request → scrape/importação das páginas de ofertas do Mercado Livre (ou CSV manual semanal);
	•	Nó Set → normaliza tudo em um único formato e salva no banco de dados (tabela produtos do Centro de Distribuição).

No Make: use o módulo HTTP + os módulos Google Sheets (como estoque temporário) + o módulo ChatGPT para normalizar.

Módulo 2 — O cérebro IA (o prompt em execução)
O prompt OFERTA MASTER PRO passa a rodar via API em vez de conversa manual:

No n8n: nó OpenAI/Anthropic/HTTP Request com o system prompt completo do OFERTA MASTER PRO e o user prompt contendo a lista de produtos brutos do Módulo 1 + suas tags de afiliado + tabela de utm_medium dos grupos.

No Make: módulo "ChatGPT/Make an AI Call" com o mesmo conteúdo.

A IA recebe os produtos brutos e devolve, por produto: título, preço verificado, desconto %, status (aprovado/reprovado conforme os critérios do prompt — nota ≥ 4.0, avaliações mínimas, vendedor confiável), link de afiliado montado, UTM completa e a copy pronta em 2 versões. Tudo é gravado de volta no Centro de Distribuição.

No n8n use Postgres/MySQL nodes (VPS) ou Supabase (gratuito). No Make, o módulo Google Sheets funciona, mas com limite de linhas — para escala, prefira o módulo Database/Supabase.

Módulo 4 — Verificação de preços (cron de horários)
Cron a cada 6–8 horas: o nó HTTP consulta o preço atual de cada produto ATIVO no banco (PA-API GetItems da Amazon é a mais prática); o nó de decisão compara com o preço registrado; se a queda ≥ 15%, marca reprice_flag=true (aciona o alerta do CAÇA AO REPRICE via Módulo 5); se a oferta expirou, marca EXPIRADO e pede reposição automática ao Módulo 1 do nicho correspondente.

Módulo 5 — Disparo programado com ritmo anti-bloqueio
O coração da operação. O prompt/regra do LINK SEGURO vira lógica no fluxo:

No n8n:
	•	Schedule Trigger nos horários de pico (7h30, 12h, 19h, 21h);
	•	SQL/Postgres seleciona os produtos ATIVOS nunca enviados (ou os reprice_flag=true, que têm prioridade — módulo CAÇA AO REPRICE);
	•	Loop com nó Wait de 3–7 minutos aleatórios entre envios (respeitando o teto de 15/dia por grupo — controle via coluna vezes_enviado e coluna data_disparo);
	•	Function/Code node sorteia a variação de domínio (40% encurtador oficial, 30% link longo, 30% Bitly) — módulo LINK SEGURO;
	•	Telegram Send Message (nó nativo, gratuito) para os canais;
	•	HTTP Request → WPPConnect/Evolution API/UltraMsg para o WhatsApp com a copy + link.

No Make: Schedule + Router + Telegram Send Message + WhatsApp (UltraMsg/Wassenger) + Sleep de 4 minutos entre operações + filtro por grupo com utm_medium diferente em cada branch.

Regra de ouro do LICO PRIMOS: cada branch do fluxo carrega um utm_medium fixo do grupo de destino (wa_geral, wa_eletronicos, tg_vip...). Assim o rastreamento por grupo continua funcionando 100% automatizado, sem você precisar anotar nada.

Módulo 6 — Monitoramento e alertas
Nó final do fluxo grava no banco cada disparo (produto, grupo, horário, link usado). Um cron semanal gera o resumo de cliques: o n8n consome o painel do Bitly via API (ou você roda manualmente uma vez por semana) e cruza com o painel de afiliados, calculando a conversão por utm_medium — e o nó de IA do prompt analisa o resultado e devolve recomendações ("priorize o grupo wa_eletronicos, converte 6,3%").

4. Implementação prática — caminho recomendado (n8n self-hosted)
Este é o caminho de menor custo e maior controle, usado pela maioria dos operadores de grupos de ofertas no Brasil 4:

	•	Contrate uma VPS (Hostinger, Contabo — R$ 30–50/mês) com Docker;
	•	Instale o n8n: docker run -d --name n8n -p 5678:5678 n8nio/n8n;
	•	Instale o Evolution API (gateway WhatsApp gratuito): docker run -d --name evolution -p 8080:8080 attendli/evolution-api — escaneie o QR code com seu WhatsApp;
	•	Crie o bot do Telegram no @BotFather e guarde o token;
	•	Suba o banco (Postgres via Docker ou Supabase gratuito);
	•	Monte o workflow: comece pelo Módulo 5 (disparo a partir de uma planilha manual para validar o anti-bloqueio), depois adicione o Módulo 2 (IA), e só então os Módulos 1 e 4 (APIs) — validar em camadas evita quebrar tudo de uma vez;
	•	Teste em 1 grupo de confiança por 24h antes de liberar (regra do LINK SEGURO que já está no prompt).

Para o Mercado Livre, o caminho prático: exporte semanalmente o CSV de produtos do portal de afiliados (ou use o scraper do repositório comunitário de link de afiliados 5) e alimente o banco; a IA gera os links de afiliado com seu publisher ID embutido.
